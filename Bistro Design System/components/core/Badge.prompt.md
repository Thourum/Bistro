Bordered uppercase mono label — file-type tags, group markers, review/CI status pills.

```jsx
<Badge>RUST</Badge>
<Badge tone="primary">GROUP</Badge>
<Badge tone="success">APPROVED</Badge>
<Badge tone="danger" variant="solid">CHANGES REQ</Badge>
```

`variant`: `outline` (default boxed) or `solid` (filled). `tone`: neutral / primary / success / danger / warning.
