Uppercase mono caption — the label above sections, metadata rows, and system chrome.

```jsx
<Eyebrow tone="primary">Workspace / Global</Eyebrow>
<Eyebrow>Files changed (12)</Eyebrow>
```

Tones: `primary` (blue section eyebrow), `muted` (gray, default), `strong` (near-black). Always renders UPPERCASE with wide tracking.
