Flat white container with a hairline border — Bistro's "card". No radius, no shadow by default.

```jsx
<Panel title="CI Checks" action={<Eyebrow>3/4</Eyebrow>}>
  …content…
</Panel>
```

`elevated` adds the single ambient shadow (use for floating menus only). `padded={false}` for full-bleed bodies like tables.
