The Bistro logo symbol — a 3D card holding a Geist "B". Use as favicon, app icon, or in a lockup.

```jsx
<BistroMark size={48} />
<BistroMark size={48} variant="inverse" />   {/* dark contexts */}
<BistroMark size={48} variant="mono" style={{ color: '#fff' }} /> {/* single-color */}
```

Square by design. Keep the cursor blue (functional accent) except in `mono`. Pair with `BistroWordmark` via `BistroLockup`.
